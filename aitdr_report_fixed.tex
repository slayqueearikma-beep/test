\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}

Le projet AITDR (Azure Intelligent Threat Detection \& Response) vise à concevoir et déployer une plateforme SOC cloud-native, automatisée et intelligente sur Microsoft Azure. La solution combine une architecture Hub-and-Spoke sécurisée, un honeypot DVWA, un pipeline ETL, Microsoft Sentinel, Azure Logic Apps, des modèles de Machine Learning non supervisés et des tableaux de bord Power BI.

    "LFI": ["../../", "etc/passwd", "/proc/self/environ"],
    "RCE": ["; wget", "; curl", "| bash", "| sh"],
    "CMDI": ["; rm", "; mkdir", "; chmod"],
}

def classify_attack(url: str, user_agent: str) -> str:
    candidate = f"{url} {user_agent}".lower()
    for attack_type, patterns in SQL_ATTACK_PATTERNS.items():
        if any(pattern.lower() in candidate for pattern in patterns):
            return attack_type
    return "Unknown"
